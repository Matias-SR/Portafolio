Agente de IA para Turismo

  • Python
  • GPT API
  • OpenWeather API

Agente de inteligencia artificial que coordina el itinerario de un turista que visita Puerto Montt y sus alrededores. Se conecta a la API de GPT y a OpenWeather para mostrar el clima en tiempo real y el pronóstico del día del tour, recomienda la vestimenta adecuada y calcula el costo de transporte según la opción elegida (vehículo propio o transporte público). Al finalizar, envía un correo confirmando la selección del usuario junto al valor estimado del recorrido.
